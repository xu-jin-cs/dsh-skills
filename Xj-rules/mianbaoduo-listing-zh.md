**一句话卖点：** 你的 AI 说"做完了"，它真的做完了吗？57 个机械门禁技能，让 Agent 的每一句"已完成"都必须过实证核验。

**商品描述：**

```
【这是什么】
一套为 AI 编程智能体（Kimi Code / Claude Code / OpenClaw 等）打造的
治理体系：57 个可组合技能，把"提示词约束"升级为"机械强制执行"。

【为什么需要它】
靠提示词约束大模型，失败是概率事件——该做的没做、缺斤短两、
伪造完成声称，是 Agent 落地的三大顽疾。本包的解法不是"写得更好的
提示词"，而是机械门禁：声称 X 已满足，就把 X 写成核验清单，
引擎逐项执行检查（文件存在性/JSON 字段/grep 计数/脚本退出码），
四态裁决（A 放行 / B 阻断并自动生成违例清单 / CLARIFY / VIOLATION），
判定禁止手写，Agent 只能照抄输出。

▸ 7 个框架技能
  gate-switch 通用门禁引擎 / dual-gates 声明+查询双闸 /
  plan-select 三槽位方案择优 / parallel-dispatch 并行调度开关
  （扇出闸+收尾闸+合并校验）/ bug-fix-strategy / scope-boundary-gate /
  idea-forge

▸ 46 个独立门禁技能（每个都是自包含技能包，单买也能跑）
  · danger_cmd_gate：rm -rf 等危险命令执行前机械拦截
  · problem_gate：问题根治决策树路由
  · loop_fuse / task_launch_gate：循环熔断，根治烧 token
  · merge_gate / receipt_gate / shard_result_gate：子分身契约校验
  · zero_residual / no_abs_path / func_signature / field_consumer：
    代码改动实证族
  · prd_inputs / deploy_admission / testlead_dispatch：流水线准入族
  ……共 46 个，各带 SKILL.md + spec + 校验脚本

▸ 4 个规则文档包（纯指令技能，挂载 AGENTS.md 即用）
  工作流治理 / 角色与工程规范 / 测试质量体系 / 治理归档

【兼容性】
· 任何支持 SKILL.md 的 Agent 运行时（agentskills.io 规范）

【许可】购买者可商用（用于自己的项目），禁止转售本包本身。
```

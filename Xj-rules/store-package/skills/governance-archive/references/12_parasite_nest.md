## 定性
寄生巢是**宿主闸门内部内置任务容器与执行方法**，归属 Gate 域组件；非钩子、非扳手，不生成独立流程节点。
> 语义：用户下达新增后置步骤指令，执行寄生动作，任务落巢休眠；无论何时下达寄生指令，全部并入该宿主闸唯一寄生巢；**每一轮宿主闸流转走到出口，都会唤醒巢内寄生虫执行**；配置不主动删除则永久驻留巢内。

## 对象编码契约
```
Gate 对象成员
‑ parasite_nest: Task[]               // 寄生巢：永久后置步骤模板队列，轮次流转不会自动清空
‑ parasite_nest_push(task)            // 对外落巢接口：新增寄生虫，追加写入模板队列
‑ parasite_nest_remove(task_id)       // 删除接口：移除巢内指定寄生虫
‑ parasite_nest_run(run_list: Task[])  // 内部执行方法：接收本轮运行副本，负责N声明、并行调度、回执等待
```

## 完整流程
### ①落巢寄生阶段（用户下达新增指令瞬间）
1. 用户指令：`在xxx业务节点之后新增步骤A、B、C`
2. 系统检索距离业务节点`xxx`最近的宿主闸门。
3. 找到宿主闸：执行寄生动作，将A/B/C作为寄生虫，**追加push进入宿主闸寄生巢模板队列**。
   - 多次下达新增指令，持续并入同一个巢，追加不覆盖；任务入巢后休眠，**不执行、不调度**。
4. 检索不到合法宿主闸：落巢失败，报错返回，任务不进入流程。

### ②巢激活执行阶段（每一轮宿主闸本体业务执行完毕，抵达闸出口）
1. 宿主闸本轮本体业务全部执行完成。
2. 判断：若`parasite_nest`模板队列不为空：
   - 将模板队列复制一份得到`run_list`本轮运行副本，**原寄生巢模板保持不变**。
   - 调用`parasite_nest_run(run_list)`。
3. 会话输出声明：本次寄生任务总数量 `N = len(run_list)`。
4. `run_list`内N个寄生虫并行启动，依托平台后台job运行；**业务层无计时器、不做业务层强杀**。
5. 每一条寄生虫执行结束（成功/失败）输出`+1`回执。
6. 集齐全部N条`+1`回执，`parasite_nest_run()`返回放行，宿主闸本轮向下游流转。
7. ⚠️本轮执行结束，**原寄生巢模板队列保留，不做clear清空；下一轮闸流转会再次复制副本执行**。

### ③删除语义
用户需要取消某个后置步骤，调用`parasite_nest_remove(task_id)`，从寄生巢模板队列移除对应任务；不删除就永久驻留，每轮闸出口自动执行。

## 边界约束
1. 巢内寄生虫互相独立无依赖；单条任务失败仅输出自身信息，不阻断其余寄生虫，不影响宿主闸已完成的主业务。
2. 任务卡死、挂起全部交由平台层`timeoutMs`兜底；业务逻辑不做超时强制放行，不生成虚拟回执。
3. 用户手动打断会话：丢弃当前正在运行的本轮`run_list`实例任务；**寄生巢原始模板队列数据完整保留，下一轮流转依旧加载执行**。
4. 无自动重试机制，单轮执行失败不会自动重试。
5. 底层平台崩溃等极端故障，会出现任务丢失、回执缺失，该风险不由寄生巢承担。
6. 寄生巢依附宿主闸存在，**不能脱离宿主闸独立作为流程节点，禁止承载主业务流程**。 【规范】
7. 宿主闸未走到出口，巢内寄生虫始终休眠，不会提前偷偷执行。

## 流转伪代码片段
```
// 宿主闸出口流转分支
if this.parasite_nest.length > 0 {
    run_list = copy(this.parasite_nest)
    await this.parasite_nest_run(run_list)
    // 不执行 clear，原始模板保留
}
// 宿主闸放行出闸
```

# UI 技能专项规则

> 专属 UI 设计全配套规则。修改 UI 流程只动此文件。

## 1. 双 Skill 兼容规则（Taste-skill / UI UX Pro Max）

### Taste-skill
- 用于逆向分析目标网站的设计体系，产出 `taste.md` + `taste.json`（设计 Token + 设计 DNA）
- 触发词：`/taste <url>`、分析设计、提取设计 Token
- 输出规范：拒绝 "clean/modern/user-friendly" 等 AI 空话，使用具体 px/hex 值和约束取舍
- 不用于：抓取数据、总结页面内容、非视觉设计任务

### UI UX Pro Max
- 用于 UI 设计阶段的交互细节落地
- 基于 Taste-skill 的审美校验结果进行设计

### 串行执行顺序
1. **素材读取** → 读取 UI 参考素材（unicom 等灵感站）
2. **Taste 审美校验** → 调用 Taste-skill 分析目标素材/竞品设计语言
3. **UI UX Pro Max 交互落地** → 基于 Taste 输出做具体 UI 设计

### 命名空间隔离
- Taste-skill 输出 → `taste.md` / `taste.json`（设计 Token）
- UI UX Pro Max 输出 → 具体 UI 组件 / 交互文档
- 两者不共享内部状态，通过文件传递设计 Token

## 2. unicom.studio / inspiration 素材站使用规范

### 检索流程
1. 打开 unicom.studio 或内置灵感站
2. 按「界面类型 + 风格关键词」检索（例如：dashboard + dark、landing page + minimal）
3. 筛选：优先选择 SVG/矢量素材，商用授权明确的素材

### 素材过滤标准
- **商用可用** → 直接采用
- **仅限个人** → 仅用作风格参考，不作为直接切图素材
- **未标注** → 按最严格授权保守处理，仅作参考

### 国内替代方案
- 当 unicom 无法访问时，使用备选方案：
  - 站酷（zcool.com.cn）— UI 界面类素材
  - 花瓣（huaban.com）— 界面设计灵感收集
  - Behance（behance.net）— 国际设计作品参考

## 3. UI 设计师完整工作流水线

```
[启动] 读取任务指派 + 项目交互文档
  → 阶段0：读取经验积累章节
  → 阶段1：质疑对齐（端类型/风格定位/交互流程/关键状态）
  → [素材读取] 打开灵感站/unicom 检索参考素材
  → [Taste 校验] 调用 Taste-skill 分析目标风格/竞品
  → 阶段2：输出全局视觉规范（颜色/字体/间距/图标）
  → 阶段3：高保真布局（组件7种状态全覆盖）
  → 阶段4：标注切图规范
  → 阶段5：交付前端 + 声明完成
  → 阶段6：视觉还原验收
  → [收尾] 写入经验积累 → 汇报项目经理
```

## 5. 调用 Skill 强制声明格式

每次调用 Skill 时，第一行必须先输出技能名称声明： 【建议】
```
[技能名称] — 用途说明
```
例如：
```
[ui-designer] — 界面设计师，输出视觉规范与高保真布局
[Taste-skill] — 逆向分析目标网站设计语言
```

## 6. UI 交付验收标准

| 维度 | 验收标准 | 偏差容忍 |
|------|---------|---------|
| 色彩 | 与视觉规范中主色/辅助色一致 | ≤ 2% 色差 (ΔE) |
| 尺寸 | 宽高与标注一致 | ≤ 1px |
| 圆角 | 与规范一致 | ≤ 1px |
| 阴影 | offset/blur/color 与规范一致 | ≤ 2px / ≤ 5% 透明度 |
| 动效 | 时长与规范一致 | ±20ms |
| 组件状态 | 7 种状态全部实现（默认/悬浮/选中/禁用/加载中/空状态/异常） | 0 缺失 |
| 控制台 | 零错误零警告 | 0 |
